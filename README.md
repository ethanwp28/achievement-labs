# Achievement Labs

Achievement Labs is a Windows desktop application for viewing and managing achievements across supported gaming platforms.

## Download

Official builds are distributed from this repository's **Releases** page. Download `AchievementLabs.exe` from the latest release.

Epic Games and Ubisoft features are still in development and are not finalized. Compatibility and behavior may change.

## Links

- Website: https://achievementlabs.duckdns.org
- Discord: available from the About page in the application
